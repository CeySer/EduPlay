4. Gemeinsame Runden und Fernseher-Modus

Wer eine Runde eröffnet oder ihr beitritt, macht seinen Spitznamen und Punktestand für die anderen Teilnehmer derselben Runde sichtbar. Übertragen werden ausschließlich Spitzname, Punkte und die Aufgaben der laufenden Runde – keine E-Mail-Adresse, kein Lernfortschritt, keine Profildaten. Eine Runde ist nur mit dem jeweiligen Code erreichbar; ein Durchblättern fremder Runden ist technisch ausgeschlossen. Abgelaufene Runden werden automatisch freigegeben.

Wird das Spiel auf einen Fernseher übertragen, zeigt der Fernseher dieselben Angaben an. Der Fernseher selbst meldet sich nicht an und kann nur die eine Runde lesen, deren Code er kennt.
